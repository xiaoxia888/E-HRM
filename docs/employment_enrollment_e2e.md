# 用人单位用工参保登记 E2E

该入口使用系统设置中保存的指定系统账号，强校验南京地区后搜索并打开“用人单位用工参保登记”。不指定系统时默认使用“江苏智慧人社账号”，也可通过 `--system "江苏政务服务平台账号"` 切换政务登录。流程只填写表单，**不会点击“确认提交”**。

## 测试 Excel

表头依次为：

`身份证号、合同增加原因、合同类别、劳动合同开始日期、劳动合同终止日期、岗位工种、参保身份、月缴费工资`

- 身份证号单元格必须使用文本格式。
- 合同增加原因接受名称或编码：新签 `1`、续签 `3`。
- 合同类别接受名称或编码：固定期限 `41`、无固定期限 `42`、完成一定工作任务 `43`。
- 无固定期限的终止日期留空；其他合同类别必须使用 `YYYY-MM-DD` 日期。
- 岗位工种接受名称或 `01` 至 `07` 编码。
- 参保身份当前为企业职工 `101`；留空时按企业职工处理。
- 新签必须填写数值型月缴费工资；智慧人社仅支持一位小数，程序会在录入前按四舍五入处理（例如 `5596.86 → 5596.9`）；续签不读取、不填写参保身份和月缴费工资。

## 命令

先校验配置、所选系统账号和 Excel，不启动浏览器：

```bash
python scripts/run_employment_enrollment_e2e.py \
  --system "江苏政务服务平台账号" \
  --input "/你的路径/参保测试.xlsx" \
  --check-input
```

执行录入并在提交前等待人工检查：

```bash
python scripts/run_employment_enrollment_e2e.py \
  --system "江苏政务服务平台账号" \
  --input "/你的路径/参保测试.xlsx" \
  --pause-after-fill
```

安装项目后，也可以将 `python scripts/run_employment_enrollment_e2e.py` 替换为 `ehrm-employment-enrollment-e2e`，两者调用同一个入口。测试原智慧人社直登时省略 `--system` 即可。

业务弹窗或页面内联提示会写入结果 Excel。当前实现不会触发最终提交。
