# 信息化人力工作台用户操作手册

## 1. 文档说明

本手册面向日常业务操作人员，介绍账号维护、权益申请查询、权益单获取、问题处理、任务查看及结果下载等操作。

首次使用前，请向管理员获取系统访问地址，并确认已经准备好江苏智慧人社、ERP 和 NocoBase 的账号信息。

## 2. 功能菜单

系统左侧提供以下菜单：

- **工作台**：查看任务运行概况和排队规则。
- **权益申请**：查看已经提交的权益申请，并直接发起权益单打印。
- **权益单获取**：从 ERP 获取申请信息，或临时导入 Excel，核对后生成权益单。
- **任务中心**：查看任务进度、错误信息和结果文件。
- **系统设置**：维护账号、下载规则、执行节奏和申请解析设置。

点击左上角的收起按钮，可以缩小或展开左侧菜单。

## 3. 首次使用

### 3.1 维护系统账号

1. 进入“系统设置”。
2. 选择“账户与连接”。
3. 在江苏智慧人社、ERP 或 NocoBase 对应行点击“编辑”。
4. 填写显示名称、登录账号及密码。
5. 江苏智慧人社还需要填写单位编号或统一社会信用代码，以及证件号码或移动电话。
6. 点击“保存”。

账号状态显示“已配置”后，相关业务页面才可以正常选择该账号。

已经保存的密码会显示为 `******`。保持该内容不变表示继续使用原密码；输入新密码后才会替换原密码。

### 3.2 设置权益单下载规则

1. 进入“系统设置”。
2. 选择“下载与任务”。
3. 设置默认保存位置。
4. 选择默认导出方式：
   - **按打印组**：同一打印组中的人员合并生成权益单。
   - **每人单独一份**：每名人员分别生成权益单。
5. 根据需要开启“权益单下载后默认上传 ERP”。
6. 点击“保存当前设置”。

## 4. 通过权益申请打印权益单

适用于已经在权益申请中维护好人员、月份和打印组的业务。

1. 进入“权益申请”。
2. 在列表中找到需要办理的申请；可以使用分页或“刷新”查看最新数据。
3. 点击申请所在行，打开申请详情。
4. 核对申请编号、状态、问题描述、申请人员、身份证、单位、部门和起止月份。
5. 根据需要开启或关闭“完成后上传 ERP”。
6. 选择用于办理的江苏智慧人社账号。
7. 点击“打印社保权益单”。
8. 系统创建任务后，进入“任务中心”查看处理进度和结果文件。

如果申请中没有人员，打印按钮将不可用。请先在申请中补充人员信息。

## 5. 从 ERP 获取申请并生成权益单

### 5.1 获取申请信息

1. 进入“权益单获取”。
2. 点击右上角“获取申请信息”。
3. 选择 ERP 账号。
4. 填写查询条件：
   - **申请编号**：可不填；填写后用于精确查询某一申请。
   - **发起日期**：可不填；填写后仅查询指定日期范围。
   - **事务类型**：默认选择“社保咨询”，可按实际业务修改。
   - **申请状态**：留空表示查询全部状态，可以选择一个或多个状态。
5. 点击“开始获取”。
6. 等待系统完成申请查询和内容解析。
7. 完成后点击“查看解析结果”。

系统会自动查询全部符合条件的申请，无需手工逐页查询。

### 5.2 核对申请数据

解析完成后，页面会显示以下内容：

- **涉及人员**：本次识别到的实际人员数量。
- **打印组**：预计生成的打印分组数量。
- **需处理问题**：必须人工处理的问题数量。
- **打印组**：查看每组人员、险种和月份。选择“每人单独一份”后，列表会按人员拆分显示。
- **人员明细**：查看全部人员资料。
- **问题信息**：查看未匹配人员、缺失字段和复核提示。
- **ERP 申请**：查看申请标题、发起人、状态及原始问题描述。

有待处理问题时，“获取权益单”按钮会暂时不可用。请先完成问题处理。

### 5.3 人工处理问题

#### ERP 未找到人员或身份证不完整

1. 进入“问题信息”。
2. 在问题行点击“人工处理”。
3. 填写或修正单位、部门、姓名、身份证号和险种。
4. 点击“保存人工处理”。

保存后系统会重新校验数据，并自动刷新人员、打印组和问题数量。

除处理问题外，也可以直接编辑已经校验通过的数据：在“打印组”中点击“编辑整组”可统一修改该组险种和月份；在展开的组内人员或“人员明细”中点击“编辑”，可修改打印组、单位、部门、姓名、身份证、险种和月份。人员修改后系统会重新计算打印组并执行一致性校验。

#### 险种或起止月份不完整

1. 在问题行点击“人工处理”。
2. 填写该打印组的险种、开始月份和结束月份。
3. 点击“保存人工处理”。

月份通过月份选择器选择，页面按 `YYYY-MM` 显示，例如 `2026-01`。系统以“ERP申请编号 + 打印组”为范围一次处理，不需要逐人重复填写。首次补充只填写组内空缺字段，不会改动其他人员已有值；如果补充值与组内已有值不同，系统会继续报告“打印组条件不一致”。

#### 打印组条件不一致

同一 ERP申请编号、同一打印组内所有人员的险种、开始月份和结束月份必须一致。出现不一致时，在问题行点击“人工处理”，核对三个条件后点击“统一整组条件”。本次操作会将确认值应用到该组全部人员。

如果申请描述没有明确说明如何分组，系统会暂按一个打印组处理条件，但仍会保留“打印组划分需要人工确认”的问题。

#### 打印组划分需要确认

1. 在问题行点击“人工处理”。
2. 选择“确认按当前打印组”或“每人单独一份”。
3. 点击“保存人工处理”。

确认后系统会重新计算打印组和预计权益单份数。

#### ERP 存在多名同名人员

1. 在问题行点击“选择人员”。
2. 根据员工编号、脱敏身份证、单位、部门和在职状态核对候选人员。
3. 选择正确人员。
4. 点击“使用选中人员”。

如果候选人员均不正确，可以点击“候选人员均不正确，改为人工录入”。

#### 未识别到申请人员

1. 在问题行点击“人工新增”。
2. 填写完整的人员资料、险种和起止月份。
3. 点击“保存人工处理”。

#### 系统或服务异常

登录失败、连接失败、请求超时或申请解析服务不可用等问题，不能通过修改人员资料解决。请根据页面提示检查账号或服务状态，然后重新获取申请信息。

### 5.4 设置执行方式

问题处理完成后，在右侧“执行设置”中：

1. 选择江苏智慧人社账号。
2. 选择导出方式：
   - **按打印组**：按照申请解析或 Excel 中的打印组生成。
   - **每人单独一份**：每名人员分别生成。
3. 查看页面显示的预计权益单份数；修改导出方式后，打印组列表也会同步按组或按人员展示。
4. 根据需要开启“下载完成后上传 ERP”。
5. 点击“获取权益单”。

任务启动后可以离开当前页面，任务不会因为切换菜单而中断。

### 5.5 查看和下载结果

任务完成后会弹出结果窗口：

- 点击“下载全部结果（ZIP）”，一次下载本次生成的全部 PDF 和处理结果 Excel。
- 单份权益单可以直接预览，也可以点击“下载当前 PDF”单独保存。
- 多份权益单可以使用“上一份”“下一份”切换，也可以从文件下拉框直接选择。
- 单个 PDF 有多页时，可以使用 PDF 阅读器工具栏中的页码或在预览区域内滚动换页。
- 页面会显示当前第几份以及总份数。
- 点击“任务中心”可以查看完整任务记录，并可再次下载完整压缩包或单个结果文件。

## 6. 临时导入 Excel 获取权益单

当申请数据暂未进入 ERP 时，可以使用 Excel 临时导入。

1. 进入“权益单获取”。
2. 点击“下载 Excel 模板”。
3. 按模板填写 ERP申请编号、打印组、单位、部门、姓名、身份证、险种、开始时间和结束时间。ERP申请编号可以留空。
4. 返回系统并点击“导入 Excel”。
5. 选择填写完成的文件。
6. 核对人员明细和打印组。
7. 设置智慧人社账号和导出方式。只有全部打印组都填写了 ERP申请编号时，才可以开启自动上传 ERP。
8. 点击“获取权益单”。

填写注意事项：

- 身份证必须为15位或18位。
- 险种只能填写养老、工伤或失业。
- 开始月份不能晚于结束月份。
- 姓名、单位和部门不能为空。
- 打印组可以留空；同一 ERP申请编号下打印组为空的人员会归入同一默认组。
- 系统按“ERP申请编号 + 打印组”组合分组。同一编号下，打印组内容相同的人员归入同一组，内容不同则分开。例如同一编号依次填写“组1、A、组1”会形成两个打印组。
- 不同 ERP申请编号即使打印组名称相同或都为空，也会分别生成权益单。
- 同一组合分组内的险种、开始时间和结束时间必须完全一致，否则导入时会提示打印组条件不一致。
- ERP申请编号留空时仍可生成权益单，但无法自动上传 ERP。

## 7. 任务中心

任务创建后，可在“任务中心”统一查看。

常见状态包括：

- **排队中**：正在等待同一账号的前一个任务结束。
- **执行中**：任务正在处理。
- **已完成**：任务已成功结束，可以查看结果文件。
- **执行失败**：任务未完成，可打开详情查看错误原因。
- **已停止**：任务被人工停止。

点击任务所在行可以打开任务详情，查看当前说明、任务编号、错误信息和结果文件。任务完成后，点击“下载全部结果（ZIP）”可下载全部 PDF 和处理结果 Excel；也可以单独下载某个结果文件。排队中或执行中的任务可以点击“停止任务”。

同一智慧人社账号的任务会自动依次执行；不同账号的任务可以同时处理。因此，同一账号出现排队属于正常情况。

## 8. 工作台

“工作台”用于快速查看：

- 正在执行的任务数量。
- 正在排队的任务数量。
- 已完成任务数量。
- 执行失败任务数量。
- 不同业务使用账号时的排队和并行规则。

左侧菜单底部会显示当前进行中的任务数量，点击后可以直接进入任务中心。

## 9. 其他系统设置

### 9.1 自动化设置

- **执行节奏**：网络稳定时可选择快速；一般情况下建议使用标准；页面加载较慢时选择稳定。
- **无结果确认时间**：查询暂时无结果时继续等待的时间。
- **预览下载等待**：权益单预览出现后等待下载的时间。
- **下载超时**：文件下载允许等待的最长时间。

修改后点击“保存当前设置”。如无特殊情况，建议保留默认值。

### 9.2 申请解析设置

“模型配置”用于选择申请内容解析方式和推理模式。一般使用管理员预设的选项即可。修改后点击“保存当前设置”，下一次获取 ERP 申请时生效。

### 9.3 系统维护

“系统维护”可以查看运行数据和日志的保存位置，也可以清理临时截图及会话快照。清理临时文件不会删除账号、业务结果或任务记录。

## 10. 常见问题

### 账号无法选择

进入“系统设置—账户与连接”，确认对应账号已经保存完整并显示“已配置”。

### 获取申请后没有数据

检查申请编号、事务类型、申请状态和发起日期。申请状态留空表示查询全部状态。

### 获取权益单按钮不可用

检查是否已经选择智慧人社账号，以及页面是否仍有待处理问题。进入“问题信息”完成处理后，按钮会自动恢复。

### 页面显示多名同名人员

点击“选择人员”，根据员工编号、身份证尾号、单位、部门和在职状态选择正确人员。

### 任务一直显示排队中

同一智慧人社账号一次只执行一个任务。请等待前一个任务完成，或在任务中心检查是否有长时间未结束的任务。

### 任务失败

进入“任务中心”，点击失败任务查看错误信息。账号失效时重新维护账号；网络或服务异常时恢复后重新发起任务；业务数据问题应在“问题信息”中人工处理。

### 完成后没有自动上传 ERP

确认任务开始前已经开启“下载完成后上传 ERP”，并确认 ERP 账号配置完整。权益单下载成功但 ERP 上传失败时，可以在任务详情中查看具体原因。

## 11. 操作建议

- 发起任务前先核对申请人员、身份证、险种和起止月份。
- 处理同名人员时重点核对员工编号、单位、部门和身份证尾号。
- 不要重复点击“获取权益单”；任务创建后到任务中心查看进度。
- 任务执行期间不要关闭系统运行程序。
- 下载完成后及时解压结果包，并核对 PDF 中的姓名、身份证、险种和缴费月份；处理结果 Excel 建议与 PDF 一并留存。
- 涉及正式业务提交时，以页面最终结果和智慧人社实际记录为准。
